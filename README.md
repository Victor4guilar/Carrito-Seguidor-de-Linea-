# README

Titulo del proyecto: Carrito Seguidor de Linea 

Programa Educativo: Ingeniería en Intrumentación Electrónica

Experiencia Educativa: Sistemas Digitales

Facilitador: Dr. José Alfonso Dominguez Chávez

Semestre: 4to

Descripción del proyecto: En este proyecto se llevará a cabo el diseño, desarrollo e implementación de un vehículo robótico (carrito) seguidor de línea, basando toda su arquitectura de control en el lenguaje de descripción de hardware Verilog. El núcleo del sistema radicará en el control digital de los motores de tracción mediante la generación de señales PWM (Modulación por Ancho de Pulso), lo que permitirá regular de manera precisa la velocidad, el torque y los giros del vehículo. Para la etapa de percepción y navegación, el carrito integrará un sistema de detección de trayectoria basado en sensores infrarrojos, cuyas lecturas serán procesadas en tiempo real por la lógica digital para ejecutar las correcciones de rumbo necesarias. Previo a la síntesis en el hardware físico, se realizará una fase exhaustiva de simulación en Verilog para validar el diseño lógico, evaluar los casos de prueba y comprobar el comportamiento de las señales de control. Como conclusión, el proyecto presentará un compendio de resultados que incluirá tanto las evidencias digitales (código fuente, diagramas de tiempo de las simulaciones y esquemáticos RTL) como las evidencias físicas, demostrando el desempeño y la viabilidad del carrito operando de forma autónoma en una pista real bajo las instrucciones del hardware programado.
